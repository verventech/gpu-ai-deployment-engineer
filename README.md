# GPU & AI Deployment Engineer — Training Program

Upskill curriculum and **printable lab worksheets** for engineers building private GPU clouds: campus labs, edge sites, and on-prem AI datacenters.

## Contents

| Document | Description |
|----------|-------------|
| [docs/curriculum.md](docs/curriculum.md) | Full program — modules 1–20, lab worksheets (Appendix A), instructor keys (Appendix B) |

## Who this is for

- AI deployment engineers
- Platform / field engineers delivering GPU private clouds to universities and enterprises
- Instructors running a 4–8 week hands-on upskill track

## How to use

1. Read **Modules 1–20** for theory and reference.
2. Print **Appendix A** from `docs/curriculum.md` (Labs A1–G1) — one worksheet per lab session.
3. Keep **Appendix B** for instructors only.
